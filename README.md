## 🚀 Projects

### 🚲 E-Bike Store Management System
> `Backend` `REST API`

Scalable backend for an e-commerce E-Bike platform. Features role-based authentication, product lifecycle management, order processing, dealer stock allocation, service booking, and admin analytics — all via REST APIs.

**Tech:** `Django` `Django REST Framework` `SQLite` `REST API` `RBAC` `OTP Email Auth`

---

### 🛡️ Insurance Fraud Detection System
> `Machine Learning` `Streamlit`

ML-powered web app to predict whether an insurance claim is fraudulent or genuine. Built a full pipeline — data preprocessing, handling class imbalance with SMOTE, training a Random Forest model, and deploying via Streamlit with SHAP-based explainability and downloadable reports.

**Tech:** `Python` `Random Forest` `SMOTE` `SHAP` `Streamlit` `scikit-learn` `Pandas`
